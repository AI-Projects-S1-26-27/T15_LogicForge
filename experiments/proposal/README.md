# Reproducible proposal evaluations

Run from the project root with Python3.10+. Research training additionally uses optional requirements-ml.txt for its GBDT comparison.

1. `python -m backend.ml.generate_optimal_data` generates3000 seeded small synthetic states and shortest-horizon proof fixtures. It exhausts shorter CSP horizons without a timeout; every SAT endpoint is independently verified. These are not real transcripts.
2. `python -m backend.ml.train_model --artifact-dir backend/ml/optimal_artifacts --epochs 150 --include-gbdt` trains the portable live MLP and research comparison. The held-out column represents a synthetic generator family, not a clinical/real-student branch study; identical heldout feature vectors are removed from training. 3000 generated states reduce to520 distinct training rows under this split. Full-curriculum transfer is experimental.
3. `python experiments/proposal/exact_validation.py` checks100 heldout small instances ×5 heuristic variants against the exact oracle. One variant uses the neural prediction directly as a research-only heuristic; the dashboard keeps composite primary ordering with neural tie-breaking.20 minimal conflicts are checked against all proper subsets. Zero observed gap on this finite test set is not a universal guarantee.
4. `python experiments/proposal/run_evaluation.py` runs200 seeded full-curriculum synthetic profiles over4 branches, eligible minors, caps20/22/24/25 and horizons7/8, with on-track, missing-course, failed-prerequisite, late-minor and accelerated profile labels. Both solvers use the same prepared candidate set. Profiles can be blocked before solving; those records are retained. Individual search budgets are .25s(E1), .1s(E2), .15s(E3); preprocessing can add time. TIMEOUT is unresolved and never treated as UNSAT. Lower budgets keep the study reproducible on a laptop; rerun with larger budgets for additional evidence.

Raw JSON contains all instance definitions and measurements. summary.json contains bootstrap confidence intervals and a paired Wilcoxon test only on pairs where both algorithms returned a plan. Runtime results include time-limited attempts; validity is conditional on returned plans. E2 configurations and E3 variants report actual nodes, runtime and status. Original experiments/ scripts/results remain historical fixtures, distinct from this current-catalogue study.

E5 requires real volunteers: see evaluation/README.md. No volunteer study is claimed completed by these synthetic experiments. Neither a final project report nor a PPT is generated by this workflow.
