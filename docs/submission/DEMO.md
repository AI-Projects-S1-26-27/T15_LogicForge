# Demonstration checklist

1. Run `python run.py --open` from the extracted project folder.
2. Keep Last finished semester at None, choose a branch, route and target 8, then generate. The transcript is empty and the plan starts in semester 1.
3. Inspect the degree audit and all semester loads. Programme-stage floors and verified load balancing prevent premature packing of advanced cores.
4. Select a completed semester to use that branch's reference-core template. Check actual passed courses before planning.
5. Open HuEl, DEL and OpEl. Select courses and assign future semesters. HuEl minimum3/9 units, DEL4/12, Open5/15; surplus DEL becomes Open once both DEL minima are met.
6. Select a minor and inspect required CDCs, credits and scheduled minor electives.
7. Choose Practice School and PS-II semester7 or8. PS-I is a separate summer placement. Full thesis uses16units alone; thesis with coursework uses9 plus6–9 elective units.
8. Generate, then run CSP vs A*. Both use identical inputs and report measured runs. Apply either verified result.
9. Move/swap a course; invalid changes explain the broken constraints. Rename the plan, export CSV/JSON and open a saved plan without regenerating.
10. Show Learned heuristic, return home and demonstrate mobile layout.

Unlisted offerings use the visible planning assumption by default. The two timetable years project parity into future terms; actual registration, GPA and campus approvals remain external. Infeasible targets show feedback rather than a claimed schedule.
